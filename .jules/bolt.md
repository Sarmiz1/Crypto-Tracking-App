## 2025-05-15 - Optimizing Mapped Sparkline Charts in Tables
**Learning:** Using Recharts `ResponsiveContainer` inside long mapped list renderers (such as in `CustomTableBody` or `SpotTable`) introduces massive layout and rendering overhead, because it instantiates a separate active `ResizeObserver` for every table row. If the table cells have fixed dimensions (e.g. 120px wide), `ResponsiveContainer` can be safely removed, and passing fixed width and height values directly to `<LineChart>` completely eliminates the `ResizeObserver` creation overhead.
**Action:** Always bypass `ResponsiveContainer` inside loops/table rows when target dimensions are fixed or can be statically computed. Specify `width` and `height` directly on `<LineChart>` to maximize scroll and rendering performance.
