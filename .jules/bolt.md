## 2026-03-06 - Removing ResponsiveContainer from loops and row renders
**Learning:** Using Recharts `<ResponsiveContainer>` inside tables or mapped list items (such as `CustomTableBody` or `SpotTable`) incurs a heavy performance cost by creating and starting a `ResizeObserver` instance for every single row. With large pages (e.g. 100 rows), this causes major layout thrashing, lagging scrolls, and high CPU usage. When the column width and height of the cell container are fixed, removing `<ResponsiveContainer>` entirely and specifying direct static `width` and `height` dimensions on the `<LineChart>` component bypasses active `ResizeObserver` creation entirely, leading to a much more efficient layout and scrolling experience.
**Action:** Always identify if a chart component is inside a loop, table, or list, and evaluate if its dimensions are fixed or can be statically defined. If so, avoid `<ResponsiveContainer>` and pass exact dimensions directly to the chart component.
