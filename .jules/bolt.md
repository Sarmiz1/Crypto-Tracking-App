## 2026-07-29 - Recharts ResponsiveContainer in Table/List Rows
**Learning:** Using Recharts `ResponsiveContainer` inside frequently rendered lists/table rows (like sparklines in `CustomTableBody` or `SpotTable`) introduces massive performance and layout overhead. This is because `ResponsiveContainer` instantiates an active `ResizeObserver` (via `react-resize-detector`) for every single row. With over 100 table rows, this creates severe rendering bottlenecks, high memory footprint, and scroll lag.
**Action:** Always avoid `ResponsiveContainer` inside loops, lists, or tables. Instead, set explicit static `width` and `height` dimensions directly on the `<LineChart>` component itself, which completely bypasses `ResizeObserver` creation and results in highly optimized rendering.
