## 2025-02-15 - ResponsiveContainer overhead in list rendering
**Learning:** Using Recharts `ResponsiveContainer` inside long mapped lists or tables creates an active `ResizeObserver` instance for each individual row. When rendering 100+ rows, this causes heavy layout observation overhead, potential rendering loops, and scroll lag. Replacing `ResponsiveContainer` with explicit, fixed `width` and `height` properties on the `<LineChart>` component entirely bypasses `ResizeObserver` creation and yields massive performance speedups in scroll responsiveness and CPU usage.
**Action:** Avoid placing `ResponsiveContainer` inside lists or table row maps. Instead, specify constant dimensions directly on the chart elements or use a single observer wrapper at the table container level.
