## 2025-08-10 - Bypassing Recharts ResponsiveContainer overhead in list rendering
**Learning:** Instantiating Recharts `ResponsiveContainer` inside rows of list or table components like `CustomTableBody` or `SpotTable` introduces severe rendering and layout overhead. This happens because `ResponsiveContainer` instantiates an active `ResizeObserver` for every single row. When the parent cell has predefined/fixed dimensions (e.g. 120px x 50px), wrapping charts in `ResponsiveContainer` is unnecessary. Directly defining `width` and `height` props on `<LineChart>` completely avoids ResizeObserver instantiation, leading to massive CPU and memory savings, faster initial renders, and smoother scrolling.
**Action:** When rendering charts in lists or tables where dimensions are known, avoid `ResponsiveContainer` entirely. Provide exact numeric dimensions directly to the chart component to optimize performance.
