## 2025-05-15 - React Context and Component Re-render Optimization
**Learning:** Recreating nested object literals inside React Context values on every render forces all consumer components to re-render, bypassing any downstream memoization. Separately memoizing the nested context sub-objects (`globalMetrics`, `cryptoListing`, etc.) and the root `value` object stabilizes references perfectly, enabling the usage of `React.memo` on heavy components like `MetricCard` and `CustomTableBody`. Also, impure rendering code like `Math.random` inside `useMemo` breaks reference equality of data arrays, rendering memoization useless.
**Action:** Always memoize context values and nested fields in providers, and use deterministic pure functions (like `Math.sin(i)`) when generating stable mock sparkline data inside rendering hooks.
